# High-Performance CUDA Kernel Optimization Portfolio

A comprehensive library of performance-optimized CUDA kernels, mathematical solvers, and parallel computing primitives.

## Architectural Taxonomy
* **dl-acceleration/**: Memory-fused deep learning primitives (Online Softmax, FlashAttention).
* **krylov-methods/**: Highly optimized 2D Conjugate Gradient iterative solvers.
* **numerical-solvers/**: Direct dense and batched solvers (LU Factorization).
* **parallel-primitives/**: Warp-shuffle reductions and hierarchical tree scans.
* **asynchronous-streams/**: Concurrency architectures demonstrating async memory/compute overlap.
* **blas-primitives/** & **sparse-linear-algebra/**: Core dense and sparse basic linear algebra subprograms.
